You edit the page. PaperTeX writes the LaTeX.

    
There is no source to type — headings, equations, figures and tables are all
      edited directly on the sheet, and the .tex file on the right updates as you go.


    
Getting around

    

      /On an empty paragraph, opens the block menu — section, equation, figure, table, list…
      $Inside any text, starts an inline formula right where the cursor is
      Ctrl+KThe command palette: search every block, symbol, structure and command, and see its
        shortcut. In running text \ opens it too (press \ twice for a backslash)
      Ctrl+EnterDrops a display equation below the current block
      EnterNew paragraph · in a list, a new item · in an equation, a new aligned line —
        on an empty last line, back to the text
      TabIndents a list item, moves to the next table cell, steps to the next slot of a formula
      ⋮The dots beside a block: change its level, numbering, label, or move it
    


    
Writing formulas — just type the name

    

      intBecomes ∫, with the caret waiting in the lower limit. Same for
        sum, prod, lim, sqrt, frac, matrix, cases, vec, hat
      EnterDone with this part — on to the next one: lower limit → upper limit → the integrand,
        numerator → denominator → after the fraction, out of an exponent. Space does the same.
        Leave a lower limit empty and it skips straight past the limits. Only on the line itself
        does Enter start a new equation line
      ↑ ↓Go to what is drawn above or below: from the line, ↑ enters the exponent, upper limit or
        numerator beside the caret and ↓ the index, lower limit or denominator; from an exponent,
        ↓ comes back down to the line
      TabSteps through every slot in turn, empty ones included. Shift+Tab goes back
      ^From inside a lower limit, jumps up to the upper one — _ jumps back down
      alphaBecomes α — every Greek letter, plus inf → ∞, partial → ∂,
        nabla → ∇, in → ∈, cdot → ⋅
      sinBecomes an upright function name, as \sin should be
      ->Becomes →  ·  <= ≤  ·  >= ≥  ·  != ≠  ·  +- ±
      BackspaceStraight after one of those puts the plain letters back
      /Fraction — whatever you just typed becomes the numerator
      ^ Superscript  ·  _ subscript  ·  type both for a stacked pair.
        ü also gives a superscript, for keyboards where ^ is a dead key
      x1A digit straight after a letter becomes an index: x1 → x₁, a12 → a₁₂, alpha3 → α₃.
        Only digits go on into it — x1+x2 and x1, x2 come out as you mean them, and
        x1^2 gives x₁². Backspace straight after puts the plain digit back
      (Brackets that grow with their contents — | gives absolute value
      \The long way round, if you prefer: \varepsilon, \bigcup, anything
      EscLeaves the formula and returns to the text
    


    
Good to know

    

      SelectHighlighting text pops up bold, italic, code, cross-reference and “make this a formula”
      Ctrl+ V an image anywhere on the page drops in a figure — dragging one in works too
      PastePasting LaTeX into a formula converts it into editable maths
      LabelsGive a heading or equation a label (⋮ → Label), then reference it from the ↪ button
      Ctrl+SDownloads the .tex — images come with it, keep them in the same folder
      Your keysEvery command, block and symbol can have a shortcut of your own, and so can any
        LaTeX snippet — 
      CompileTypesets it with real LaTeX in your browser — nothing is uploaded. First run downloads the engine
